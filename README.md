# Соціальна мережа студентів

## Опис проєкту
JavaFX-додаток для керування соціальною мережею студентів. Дозволяє:
- Додавати/редагувати/видаляти студентів та групи
- Керувати дружбою між студентами
- Виконувати складні запити (топ-5 друзів, аналіз груп)

## Технології
- Java 17
- JavaFX 21
- PostgreSQL 18
- Maven
- JDBC

## Схема бази даних

| Таблиця | Опис |
|---------|------|
| students | Студенти (id, first_name, last_name, email) |
| groups | Групи (id, name, headman_id) |
| student_groups | Зв'язок студентів з групами |
| friendships | Дружба між студентами |

## Проєкт зроблено Стадницький Павлом Володимировичем, з групи ІН-32/2

## Правила Git
- main – стабільна версія
- feature/* – нові функції
- Коміти мають бути змістовними

## Запуск проєкту
